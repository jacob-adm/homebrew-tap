# homebrew-tap

Homebrew formulae for command-line tools by jacob-adm.

## Install

```
brew install jacob-adm/tap/glassbox
```

Homebrew downloads the release archive for your platform and checks it against the SHA-256 in the
formula before installing.

## Formulae

| Formula | What it does | Platforms |
|---|---|---|
| [glassbox](https://github.com/jacob-adm/glassbox) | Security and systems auditing for AI agents and local workloads | macOS on Apple silicon; Linux x86-64 and ARM64 |

## Updating

```
brew update && brew upgrade glassbox
```
